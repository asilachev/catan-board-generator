Правила сценария

    Ссылки на правила относительные, поэтому положите рядом с этим файлом catan-rules.pdf (базовая игра, Мир Хобби, версия 1.1) и catan-morehodi-2025-rules.pdf («Мореходы», версия 1.0) — имена должны совпадать. Ссылка в карточке сценария открывает нужную страницу брошюры: номера страниц взяты из самих правил, а переход по #page= работает в браузерном просмотрщике PDF.

    Составы гексов, номерных жетонов, гаваней и условия победы взяты из этих же брошюр. Очертания островов подобраны по смыслу сценария и не повторяют схемы гекс в гекс — в правилах «Мореходов» раскладку внутри островов и так разрешено менять. Дополнение для 5–6 игроков в брошюре не описано, для него взято стандартное распределение.
